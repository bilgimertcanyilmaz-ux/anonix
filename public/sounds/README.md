# Ses dosyaları

Bu klasöre iki kısa ses dosyası ekleyin (uygulama bu yolları kullanır):

- `public/sounds/notification.mp3` — yeni bildirim sesi (kısa, rahatsız etmeyen)
- `public/sounds/message.mp3` — yeni mesaj sesi (farklı, kısa)

Öneri: 0.3–1 saniyelik, düşük ses seviyeli, telifsiz "pop/ping" sesleri.
Telifsiz kaynaklar: pixabay.com/sound-effects, mixkit.co, freesound.org

Dosyalar yoksa uygulama hata vermez; ses sessizce atlanır.
Dosya adlarını birebir `notification.mp3` ve `message.mp3` yapın.
